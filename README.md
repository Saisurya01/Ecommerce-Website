# Ecommerce Website

A fully responsive and visually engaging e-commerce website built using **HTML**, **CSS**, and **JavaScript**. This project features smooth animations, interactive UI elements, and an intuitive shopping experience — all without a backend.

**Live Demo:** https://saisurya01.github.io/Ecommerce-Website/

---

## 🛍️ Overview

This Ecommerce Website presents a clean, modern layout for browsing products and exploring features commonly found in shopping sites. It demonstrates front-end development skills including layout design, animation effects, and DOM manipulation using vanilla JavaScript.

The project is ideal for beginners and intermediate developers who want to learn advanced HTML/CSS layouts and interactive JavaScript features.

---

## 🌟 Features

- Responsive layout for desktop and mobile
- Smooth transition and animation effects
- Product grid with hover effects
- Navbar with toggle functionality
- Interactive UI using JavaScript
- No backend required

---

## 🧠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
